# Política de Privacidade **Controle para Ventisol** **Última atualização: 18 de setembro de 2026** ## 1. Sobre o aplicativo O **Controle para Ventisol** é um aplicativo desenvolvido para funcionar como controle remoto de equipamentos compatíveis, utilizando a tecnologia de **infravermelho (IR)** disponível em dispositivos compatíveis. O aplicativo permite enviar comandos ao equipamento, como ligar, desligar e controlar as funções disponibilizadas pelo dispositivo. ## 2. Coleta de dados pessoais O **Controle para Ventisol não coleta, armazena, vende ou compartilha dados pessoais dos usuários**. O aplicativo não exige criação de conta ou cadastro e não solicita informações como: * Nome; * Endereço; * Número de telefone; * E-mail; * CPF; * Informações financeiras; * Contatos; * Fotografias; * Mensagens; * Dados de localização. ## 3. Uso do infravermelho O aplicativo utiliza o recurso de **infravermelho (IR)** do dispositivo, quando disponível, exclusivamente para transmitir comandos ao equipamento compatível. Os sinais infravermelhos são utilizados para executar a função de controle remoto. O aplicativo não utiliza o infravermelho para coletar informações pessoais ou identificar o usuário. ## 4. Permissões O aplicativo utiliza somente os recursos necessários para seu funcionamento. O uso do recurso de infravermelho não significa que o aplicativo tenha acesso à localização, câmera, microfone, contatos ou outros dados pessoais do usuário. ## 5. Armazenamento de dados O aplicativo não mantém servidores próprios destinados ao armazenamento de dados pessoais dos usuários. Os comandos enviados pelo aplicativo ao equipamento são utilizados para a operação do controle remoto e não são enviados para servidores externos para armazenamento. ## 6. Compartilhamento de dados O **Controle para Ventisol não compartilha dados pessoais dos usuários com terceiros**. Também não vende, aluga ou comercializa informações pessoais. ## 7. Serviços de terceiros O aplicativo não utiliza serviços externos destinados à coleta ou comercialização de dados pessoais. Caso sejam adicionados futuramente serviços ou funcionalidades que alterem o tratamento de dados, esta Política de Privacidade será atualizada. ## 8. Segurança Como o aplicativo não coleta ou armazena dados pessoais dos usuários, não existe uma base de dados pessoal do usuário mantida pelo aplicativo. São adotadas medidas razoáveis para preservar o funcionamento e a segurança do aplicativo. ## 9. Privacidade de crianças O aplicativo não solicita dados pessoais e não foi desenvolvido com a finalidade de coletar informações pessoais de crianças. ## 10. Retenção e exclusão de dados O aplicativo não mantém dados pessoais dos usuários em servidores próprios. Consequentemente, não existe uma base de dados pessoal mantida pelo desenvolvedor que necessite de solicitação de exclusão. ## 11. Alterações nesta Política de Privacidade Esta Política de Privacidade poderá ser atualizada caso ocorram alterações no aplicativo, nas funcionalidades oferecidas ou nas exigências legais aplicáveis. A versão mais atual estará sempre disponível nesta página. ## 12. Contato Para dúvidas relacionadas a esta Política de Privacidade ou ao aplicativo **Controle para Ventisol**, o usuário poderá entrar em contato com o desenvolvedor por meio do canal de contato disponibilizado na página do aplicativo na Google Play. ## 13. Aceitação Ao utilizar o aplicativo **Controle para Ventisol**, o usuário declara estar ciente desta Política de Privacidade. **Controle para Ventisol** Brasil **Última atualização: 18/09/2026**
